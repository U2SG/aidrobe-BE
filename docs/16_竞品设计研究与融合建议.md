# 竞品设计研究与融合建议

> 文档版本：V1.0  
> 研究对象：Acloset、Whering、Indyx、Stylebook、Cladwell、Alta 等数字衣橱 / AI 穿搭产品  
> 目标：提炼可借鉴机制，并融入 Aidrobe V4 产品白皮书。

---

## 1. 竞品研究结论

数字衣橱赛道已经验证了几个明确方向：

1. 用户确实需要把真实衣橱数字化。
2. 单纯“衣服管理”不够，必须连接到“今天怎么穿”。
3. 降低衣物录入成本是所有产品的关键瓶颈。
4. 穿搭推荐必须结合天气、场景、历史穿着与个人审美。
5. 真实单品图、拼搭板、日历、统计、旅行打包是成熟产品的常见基础能力。
6. 竞品普遍弱在“现实取衣成本”“时间压力”“中国内容平台/电商导入”和“出门前决策”。

Aidrobe V4 的差异化不应是“我也有 AI”，而应是：

> 在真实衣橱基础上，结合衣物状态、存放位置、时间压力和个人风格，给出现在最可执行的穿搭决策。

## 2. 竞品一：Acloset

### 2.1 值得借鉴的设计

Acloset 的核心表达是“Your AI-picked outfit, every day”。它强调：

- AI 自动组织衣橱。
- 每天推荐穿搭。
- 支持从单张照片录入衣服。
- 支持从 Amazon、Zara、Shein 等渠道导入。
- 跟踪风格与衣橱使用。

### 2.2 对 Aidrobe 的启发

Acloset 的优点是冷启动心智简单：

```text
拍照/导入衣服 → AI 整理 → 每日推荐
```

Aidrobe 可以吸收这套低门槛表达，但要进一步强化：

```text
每日推荐不是泛推荐，而是根据“出门时间 + 可穿状态 + 存放位置”排序。
```

### 2.3 可融入设计

- 首页主标题可以类似：
  - “今天出门穿什么？”
  - “根据你现在还有多久出门，给你 3 套可直接穿的方案。”
- 新用户 onboarding 重点不是让用户管理衣服，而是承诺：
  - “录入 10 件通勤单品，明天开始自动推荐。”
- 导入页加入“从购物平台/商品链接导入”。

## 3. 竞品二：Whering

### 3.1 值得借鉴的设计

Whering 是偏社区和衣橱洞察的产品，值得借鉴的能力包括：

- 数字衣橱。
- 从零售网站添加图片。
- 背景移除。
- 社交衣橱与朋友衣橱。
- Moodboards / Wishlists。
- Cost-per-wear、wear rate、color palette、closet longevity。
- Dress Me 式随机搭配。
- Travel packing lists。
- “Unpacked” 类似年度/季度衣橱复盘。

### 3.2 对 Aidrobe 的启发

Whering 证明了“衣橱洞察”本身可以成为留存点，但 Aidrobe 不应该早期做重社区。更适合吸收的是：

- 衣橱统计。
- 穿着复盘。
- 色彩偏好。
- 购物前 sense-check。
- Moodboard / 灵感来源。

### 3.3 可融入设计

V4 增加“衣橱洞察”模块：

```text
- 本月最常穿单品
- 本月重复搭配
- 闲置超过 60 天单品
- 成本/穿着次数
- 常用色彩
- 风格关键词变化
- 冲动购买提醒
```

这些数据能增强用户对产品的长期依赖。

## 4. 竞品三：Indyx

### 4.1 值得借鉴的设计

Indyx 的产品设计非常适合 Aidrobe 借鉴，尤其是降低录入成本方面：

- 自动去背景。
- 优化图片质量。
- AI 自动标注类别、子类别、颜色。
- 支持购物 receipt forwarding。
- 支持粘贴商品链接导入。
- 支持专业 Archivist 上门整理衣橱。
- 拖拽式 outfit board。
- 成本/穿着次数分析。
- OOTD 自拍记录。
- 朋友共享衣橱。
- Style Quiz 和 Style Workshop。
- Packing list / Collection。

### 4.2 对 Aidrobe 的启发

Indyx 说明一件事：

> 建库成本是数字衣橱最大的摩擦点，必须提供多入口导入，而不是只靠用户拍照。

### 4.3 可融入设计

Aidrobe V4 应吸收三类能力：

#### 1）多来源入库

```text
拍照 / 相册 / 分享 / 商品链接 / 订单截图 / 购物邮件 / 小红书/抖音链接
```

#### 2）真实穿搭记录

```text
推荐穿搭 → 用户选择“今天穿这套” → 可上传 OOTD 自拍 → 记录当天感受
```

#### 3）人工增强服务的远期可能

如果未来产品商业化，可以提供：

```text
- 专业衣橱整理服务
- 远程造型师 Lookbook
- 高级会员人工复盘
```

但这不进入 V1/V2。

## 5. 竞品四：Stylebook

### 5.1 值得借鉴的设计

Stylebook 是比较成熟的手动衣橱管理工具，它的重点是：

- 真实衣服导入。
- 服装拼贴式 outfit board。
- Calendar 记录穿着。
- Packing lists。
- Cost per wear。
- Style Stats。
- Inspiration Library。
- Custom Categories。
- iCloud Backup / Sync。
- 搜索与筛选。

### 5.2 对 Aidrobe 的启发

Stylebook 的强项是“用户可控”。这对 AI 产品很重要，因为 AI 推荐如果完全黑盒，会降低用户信任。

Aidrobe 应该借鉴：

- 用户可编辑衣物标签。
- 用户可自由拼搭。
- 用户可计划未来几天穿搭。
- 用户可查看历史日历。
- 用户可把灵感和真实衣橱分开管理。

### 5.3 可融入设计

V4 增加两个模块：

```text
1. Outfit Board：真实单品图拼搭板
2. Outfit Calendar：穿搭日历与历史复盘
```

推荐不只是一次性结果，而是可以被保存、编辑、计划、复用。

## 6. 竞品五：Cladwell

### 6.1 值得借鉴的设计

Cladwell 强调：

- 使用已有衣服获取每日 outfit ideas。
- 结合天气和穿着习惯。
- 支持拍照添加衣服。
- 支持 capsule wardrobe 和旅行打包。
- Ask Cladwell 类 AI 问答。
- 识别衣橱缺口。

### 6.2 对 Aidrobe 的启发

Cladwell 的价值表达很接近 Aidrobe：

```text
不要买更多，先更好地穿你已有的衣服。
```

Aidrobe 可以继承这个长期价值观，但在交互上更聚焦：

```text
今天出门前，我现在该穿哪套？
```

### 6.3 可融入设计

V4 可加入“Ask Aidrobe”：

```text
- 今天有客户会，穿哪套更稳？
- 这件衬衫还能怎么搭？
- 我下周出差 3 天，帮我打包。
- 我的衣柜缺什么基础款？
```

但 Ask 功能不应该替代每日推荐，而是作为解释和探索入口。

## 7. 竞品六：Alta

### 7.1 值得借鉴的设计

Alta 代表了新一代 AI closet 的方向：

- 上传或从互联网导入衣服。
- 图片增强。
- 穿搭规划。
- 成本/穿着计算。
- worn item tagging。
- 数字 avatar 预览。

### 7.2 对 Aidrobe 的启发

Alta 的 avatar/try-on 很吸引人，但 Aidrobe 不应在 V1-V2 过早主推虚拟试穿。原因是：

- 生成图可能改变真实衣物版型。
- 对用户隐私要求更高。
- 推理成本更高。
- 早晨决策场景不一定需要完整上身图。

### 7.3 可融入设计

建议将虚拟试穿放到 V4 增强能力：

```text
真实单品图卡片 → 拼搭板 → 可选虚拟预览
```

即，先建立信任，再提供增强视觉化。

## 9. 应融入 Aidrobe V4 的设计清单

### P0：立刻融入

```text
- 多来源导入：拍照、相册、分享、链接、截图
- 自动去背景与图片增强
- 真实单品图卡片推荐
- time_sensitivity 推荐表达
- location / status / time_cost 入推荐
- style_sources 替代 style_inspirations
```

### P1：下一阶段融入

```text
- Outfit Board 拼搭板
- Outfit Calendar 穿搭日历
- OOTD 自拍记录
- Cost-per-wear / wear rate
- 色彩画像 / 风格画像
- 旅行 packing list
```

### P2：商业化与长期壁垒

```text
- Ask Aidrobe AI stylist
- 购物前 sense-check
- 衣橱缺口分析
- 远程造型师服务
- 可选虚拟试穿
- 半年度/年度衣橱复盘报告
```

## 10. Aidrobe V4 的差异化表达

竞品多数在讲：

```text
Organize your closet.
Get outfit ideas.
Track what you wear.
```

Aidrobe 应该讲：

```text
出门前，基于你真实拥有、现在能穿、找得到、来得及拿的衣服，给你最合适的穿搭决策。
```

建议产品核心 slogan：

> 不是更多衣服，而是每天更快穿对。

或：

> 你的衣橱，终于开始帮你做决定。
