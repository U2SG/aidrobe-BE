# AI 通勤穿搭助手：版本设计（V1 / V2 / V3）

## 1. 产品定义

### 1.1 产品名称（暂定）
AI 通勤穿搭助手

### 1.2 一句话描述
拍下你的衣服，记录状态与位置；每天出门前，基于你的衣橱和剩余准备时间，给你 3 套可执行穿搭建议。

### 1.3 产品核心价值
- 帮用户减少早晨“今天穿什么”的决策成本
- 在有限时间下提供现实可执行的穿搭方案
- 基于真实反馈持续优化，更懂用户自己的风格

---

## 2. 版本设计原则

### 2.1 先跑闭环，再做增强
优先验证：
1. 用户是否愿意录入衣服
2. 用户是否真的会查看推荐
3. 用户是否会按推荐穿
4. 用户是否会给反馈

### 2.2 先做“可执行推荐”，而不是“炫技推荐”
产品第一阶段目标不是做最惊艳的时尚 AI，而是做：
- 现实中拿得到
- 当前状态能穿
- 时间上来得及
- 场景上不出错

### 2.3 先展示用户真实单品，再考虑生图
推荐展示优先级：
1. 真实单品图 + 文字解释
2. 自动拼搭板
3. 虚拟试穿 / 上身生图

---

## 3. V1：MVP 可验证版

## 3.1 版本目标
验证最小产品闭环：
录入衣服 -> 生成推荐 -> 用户查看 -> 用户选择 -> 用户反馈

## 3.2 用户价值
- 早晨不必重新想搭配
- 从已有衣服中得到 3 套可选答案
- 在通勤场景中快速做决策

## 3.3 核心功能
### 必做
- 拍照 / 相册导入衣服
- 链接导入 / 分享导入（作为低成本建库入口）
- AI 识别基础属性：品类、颜色、季节粗分类
- 用户编辑：状态、位置、名称
- 设置预计出门时间
- 每日 3 套推荐
- 用户反馈：穿了 / 喜欢 / 不喜欢 / 原因

### 不做
- 天气联动
- 小红书 / 抖音风格深度理解
- 自动同步电商全部购买记录
- 虚拟试穿
- 社区

## 3.4 推荐逻辑
- 只使用可穿状态衣物
- 基于规则生成候选组合
- 输出三种类型：
  1. 最稳妥
  2. 最省时间
  3. 更有风格感
- 用 LLM 只做解释与轻量排序，不做完全自由生成

## 3.5 核心指标
- 首日录入件数
- 首周录入件数
- 推荐打开率
- “今天穿这套”点击率
- 推荐反馈率
- 7 日留存

## 4. V2：推荐增强版

## 4.1 版本目标
让推荐更像“今天的你”，而不是一组静态搭配。

## 4.2 核心增强点
### 天气感知
- 温度
- 降雨
- 风力
- 体感温度

### 场景感知
- 普通办公
- 开会
- 见客户
- 外出
- 周五轻松

### 时间感知增强
- T-180 分钟：完整搭配
- T-60 分钟：稳妥搭配
- T-15 分钟：极速方案

### 现实可执行性增强
- 取衣成本建模
- 状态更细化：待洗、需熨烫、换季收纳等
- 最近穿过的衣物降权

### 反馈学习
- 颜色偏好
- 正式度偏好
- 风格偏好
- 复杂度容忍度
- 穿了但没点赞 vs 点赞但没穿

## 4.3 新增功能
- 天气接入
- 场景选择
- 更细反馈标签
- 重复穿搭控制
- 穿搭收藏
- 胶囊衣橱建议（轻量版）

## 4.4 核心价值升级
从“今天穿什么”升级到：
“结合天气、场景、时间与状态，推荐今天最合适的方案”。

---

## 5. V3：风格智能版

## 5.1 版本目标
从穿搭助手进化为个人风格系统。

## 5.2 核心增强点
### 外部风格灵感输入
- 小红书链接 / 截图
- 抖音链接 / 截图
- 商品链接 / 商品图

### 风格理解
系统识别用户喜欢的是：
- 配色
- 廓形
- 材质感
- 正式度
- 叠穿方式
- 某件单品的角色

### 灵感映射
基于用户现有衣橱，输出：
- 类似感觉搭配
- 替代单品
- 缺失单品建议

### 长期成长能力
- 风格画像
- 穿搭满意度趋势
- 衣橱利用率分析
- 月度穿搭复盘
- 出差打包建议

## 5.3 新增功能
- 外部内容导入解析
- 风格 embedding 聚类
- 相似穿搭检索
- 月报 / 周报
- 旅行打包推荐

## 5.4 产品价值升级
从“帮你穿”升级到：
“越来越懂你，帮你形成自己的稳定风格系统”。

---

## 6. 版本取舍总结

## 6.1 V1 解决的问题
今天穿什么

## 6.2 V2 解决的问题
今天在当前条件下怎么穿最合适

## 6.3 V3 解决的问题
我真正适合什么风格，以及如何持续进化

---

## 7. 版本边界建议

### V1 边界
只验证晨间决策闭环，不追求平台联动的完整性。

### V2 边界
开始做“条件感知推荐”，但不急于做重型内容生态。

### V3 边界
在 V1/V2 数据积累足够后，再做风格智能和外部灵感映射。

---

## 8. 推荐推进顺序

1. V1：先把衣橱建起来，把早晨推荐跑起来
2. V2：让推荐更准、更现实、更高频
3. V3：让系统形成个性化风格壁垒
