# 数据表结构设计（V1）

## 1. 文档目标

给出 V1 的核心数据模型，帮助后端、算法与数据分析统一字段语义。本文以关系型数据库为主，向量字段可结合 pgvector 或单独向量库实现。

---

## 2. 设计原则

1. 用户可编辑字段与 AI 识别字段分层保留
2. 支持图片、链接、分享等多来源导入
3. 支持异步任务状态管理
4. 支持推荐记录、选择记录与反馈记录
5. 尽量保留后续 V2 / V3 可扩展空间

---

## 3. 表清单

### 主表
- `users`
- `user_settings`
- `wardrobe_items`
- `wardrobe_item_images`
- `import_tasks`
- `external_sources`
- `daily_recommendations`
- `outfits`
- `outfit_items`
- `outfit_feedback`
- `wear_history`

### 辅助表（可选）
- `item_embeddings`
- `item_tags`
- `operation_logs`

## 4. 详细结构

## 4.1 users

| 字段 | 类型 | 说明 |
|---|---|---|
| id | bigint / uuid | 主键 |
| mobile | varchar | 登录标识，可为空 |
| nickname | varchar | 昵称 |
| avatar_url | varchar | 头像 |
| status | smallint | 账号状态 |
| created_at | timestamp | 创建时间 |
| updated_at | timestamp | 更新时间 |

---

## 4.2 user_settings

| 字段 | 类型 | 说明 |
|---|---|---|
| id | bigint / uuid | 主键 |
| user_id | bigint / uuid | 用户 ID |
| departure_time | time | 预计出门时间 |
| push_enabled | boolean | 是否开启推荐推送 |
| timezone | varchar | 时区 |
| locale | varchar | 语言 / 地区 |
| created_at | timestamp | 创建时间 |
| updated_at | timestamp | 更新时间 |

### 索引建议
- `unique(user_id)`

---

## 4.3 wardrobe_items

| 字段 | 类型 | 说明 |
|---|---|---|
| id | bigint / uuid | 主键 |
| user_id | bigint / uuid | 用户 ID |
| source_type | varchar | camera / album / link / share / screenshot / manual |
| source_platform | varchar | taobao / jd / xiaohongshu / douyin / unknown |
| title | varchar | 衣物名称 |
| category | varchar | top / bottom / outerwear / dress / shoes |
| sub_category | varchar | shirt / knitwear / trousers / skirt ... |
| color_main | varchar | 主颜色 |
| color_secondary | varchar | 辅颜色，可为空 |
| season_tags | jsonb | 季节标签数组 |
| style_tags | jsonb | 风格标签数组 |
| formality_score | smallint | 正式度 1~5 |
| status | varchar | wearable / laundry / washed_not_stored / ironing / stored |
| location | varchar | main_closet / drawer / box / shoe_cabinet / other |
| confidence_score | numeric | AI 初识别置信度 |
| latest_worn_at | timestamp | 最近穿着时间 |
| created_at | timestamp | 创建时间 |
| updated_at | timestamp | 更新时间 |
| deleted_at | timestamp | 软删除时间 |

### 索引建议
- `idx_wardrobe_items_user_id`
- `idx_wardrobe_items_user_status`
- `idx_wardrobe_items_user_category`
- `idx_wardrobe_items_user_location`

### 说明
- `season_tags` 与 `style_tags` 初期可用 jsonb，后续数据量上来后可拆关系表
- `status` 与 `location` 建议统一枚举，避免前后端不一致

---

## 4.4 wardrobe_item_images

| 字段 | 类型 | 说明 |
|---|---|---|
| id | bigint / uuid | 主键 |
| item_id | bigint / uuid | 衣物 ID |
| image_type | varchar | original / standard / thumbnail / cutout |

| height | int | 高 |

## 4.11 wear_history

| 字段 | 类型 | 说明 |
|---|---|---|
| id | bigint / uuid | 主键 |
| user_id | bigint / uuid | 用户 ID |
| outfit_id | bigint / uuid | 方案 ID |
| selected_at | timestamp | 选择“今天穿这套”的时间 |

### 说明

## 4.12 item_embeddings（可选）

|---|---|---|
| id | bigint / uuid | 主键 |

### 说明
- 如果使用 pgvector，可直接存 `vector`

## 6. 数据流说明

### 导入链路
`import_tasks` -> `external_sources` / 图片处理 -> 用户确认 -> `wardrobe_items` + `wardrobe_item_images` + `item_embeddings`

### 推荐链路
用户设置 + 可穿衣物 -> `daily_recommendations` -> `outfits` -> `outfit_items` -> 用户选择 / 反馈 -> `wear_history` + `outfit_feedback`
